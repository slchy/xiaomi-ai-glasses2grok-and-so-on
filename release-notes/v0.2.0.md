# v0.2.0 — 包名迁移（breaking）

**这是 breaking release**：所有 Kotlin 包名与 Maven 坐标都换了，升级要改 import 和依赖坐标。
业务行为与 v0.1.1 一致，没有功能增删。

**This is a breaking release.** Every Kotlin package and every Maven coordinate changed.
Behaviour is identical to v0.1.1 — nothing was added or removed.

## 迁移 / Migration

```diff
- implementation("com.miaiglasses:sdk:0.1.1")
- implementation("com.miaiglasses:sdk-ktx:0.1.1")   // 可选
+ implementation("io.github.slchy.glasses2grok:sdk:0.2.0")
+ implementation("io.github.slchy.glasses2grok:sdk-ktx:0.2.0")   // optional
```

```diff
- import com.miaiglasses.sdk.GlassesSession
- import com.miaiglasses.core.session.GlassesEvent
+ import io.github.slchy.glasses2grok.sdk.GlassesSession
+ import io.github.slchy.glasses2grok.core.session.GlassesEvent
```

规则只有一条：`com.miaiglasses` → `io.github.slchy.glasses2grok`，其余（类名、方法名、
包结构、模块划分）全部不变。

One rule only: `com.miaiglasses` → `io.github.slchy.glasses2grok`. Class names, method
names, package structure and module split are unchanged.

## 为什么改 / Why

`com.miaiglasses` 是个无法验证归属的前缀。`io.github.<user>` 是按持有者分配的命名空间，
和仓库地址 `github.com/slchy/xiaomi-ai-glasses2grok-and-so-on` 一一对应 —— 谁维护、
代码从哪来，看坐标就知道。顺带把 Maven group 一起改，避免"坐标与包名两套名字"。

`com.miaiglasses` claims an ownership nobody can verify. `io.github.<user>` is a namespace
tied to the account that actually hosts the repository, so the coordinates now say who
maintains this and where it comes from.

## 注意 / Notes

- **这不是 drop-in 升级。** Gradle 不会把 `com.miaiglasses:sdk` 当作
  `io.github.slchy.glasses2grok:sdk` 的替代，两个坐标可以并存 —— 混用会出现两份类。
- 旧坐标 `com.miaiglasses:*` 不再发布新版本；v0.1.0 / v0.1.1 的产物仍然可用。
- Android 示例 App 的 `applicationId` 同步改为
  `io.github.slchy.glasses2grok.sample`。装上后是**另一个 App**，与旧版不能覆盖升级，
  需要先卸载旧版。

- **Not a drop-in upgrade.** Gradle treats the two coordinates as different libraries;
  having both on the classpath gives you two copies of every class.
- Old coordinates `com.miaiglasses:*` will not receive new versions. v0.1.0 / v0.1.1
  artifacts remain available.
- The sample app's `applicationId` moved to `io.github.slchy.glasses2grok.sample`; it
  installs as a separate app, so uninstall the old one first.
