# v0.2.3 — 云端语音后端 + 高清照示例

这一版把项目补成两半：`sdk/` 管「手机 ↔ 眼镜」，新增的 `cloud/` 管「手机 ↔ 大模型」。
SDK 侧是**纯增量**：没有改任何已有签名，只新增了一个下行状态帧的方法。

This release completes both halves of the project: `sdk/` drives the phone ↔ glasses link,
and the new `cloud/` turns the glasses uplink into a conversation. The SDK change is
**additive only** — no existing signature changed.

## 新增：`cloud/`（MIT）

手机把眼镜的上行 mSBC **原样**转发过来，云端解码 → 判停 → ASR → Agent → TTS，
再把 PCM 流式推回手机播放。

- `src/` 传输与分帧、上行管道、能量门、句子合并、对话/会话状态机、拍照收件箱、
  回合执行器、原始档案、离线补播、provider 契约
- `tests/` 纯逻辑单测（不需要网络与凭据）
- `tools/fake-phone.ts` 假手机：不接真机也能跑通整条链路
- `mcp/` 把相机与会话控制挂成 agent 工具的桥
- 只需要 Node 22.6+（直接跑 `.ts`）与 `ffmpeg`；`onnxruntime-node` 是惰性加载，
  只在启用 silero-vad 时才需要
- **不含任何凭据**：`.env` / `tokens.txt` / 自签证书都在 `.gitignore` 里，
  仓库只有空模板 `.env.example`；2.3 MB 的 `silero_vad.onnx` 不入库，
  `models/` 里有获取地址与许可

三行跑通（不需要真机、不需要密钥）：

```bash
cd cloud
node src/main.ts --listen 8766 --stt canned --tts silent --agent echo   # 终端 1
node tools/fake-phone.ts --port 8766 --sbc ../some-capture.sbc          # 终端 2
```

## 新增：示例 App 的两条完整链路

- **语音通道**：`Wire`（云端线协议）/ `VoiceLink`（TLS + 心跳 + 下行播放）/
  `PcmPlayer` / `Tls`（自签 CA pinning）
- **协作式高清照**：`PhotoFsm`（纯相位机，可单测）+ `PhotoJob`（执行器）+
  `HighResPhoto`（P2P 拉原图、缩图、上行）。程序化快门不写相册，所以走
  「就绪 → 等用户按快门 → 拉图」的两段式，失败即返回
- `DashboardActivity`：指示灯跟着播报走、摘下即停转发、空闲自动结束会话让眼镜回待机

## 公共 API 增量

```kotlin
// 新增：任意 Voice id=5 六字段（0 值也必须显式写出）
GlassesSession.syncVoiceStatus(voice = 0, tts = 0, mediaPlay = 0, image = 0, operating = 0, device = 0)
// 底层同一份编码
VoiceCodec.syncStatusPayload(...)
```

已确认的行为只有一条：**六字段全 0 会让眼镜立刻停止采集**。其余字段与指示灯的关系
仍未逐项实测，KDoc 里已标注，别当稳定契约用。
